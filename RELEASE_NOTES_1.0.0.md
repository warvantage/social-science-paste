# Social Science Paste v1.0.0

The first stable release of **Social Science Paste**, a lightweight macOS clipboard utility designed for academic writing.

Normal paste often keeps too much formatting. Plain-text paste can remove formatting that still carries meaning. Social Science Paste sits between the two.

## Core feature

Choose independently whether to preserve:

- **Bold**
- *Italic*
- Hyperlinks

The three options can be enabled or disabled in any combination while unwanted source fonts, sizes, colours and highlighting are removed.

## Also included

- Pause / Resume clipboard cleaning
- Launch at Login
- English / 中文 interface
- Copy-time clipboard cleaning
- Normal `⌘V` paste
- Local-only clipboard processing

## Scope

This release focuses on text and rich text. Images, files, PDF objects and structured tables are left untouched.

## Requirements

- Apple Silicon Mac
- macOS 11 Big Sur or later
