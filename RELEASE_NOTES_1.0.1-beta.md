# Social Science Paste v1.0.1 Beta

This beta builds on v1.0.0 with improved compatibility for text copied from **Microsoft Word / Office**.

## Included

- Independently selectable **Bold**, *Italic* and Hyperlink preservation
- Pause / Resume
- Launch at Login
- English / 中文 interface
- Copy-time clipboard cleaning
- Normal `⌘V` paste

## What is new

Microsoft Office can place multiple representations of copied text on the macOS clipboard. This beta improves how Social Science Paste recognises textual Office clipboard content so it can be cleaned more reliably.

Feedback is especially useful for Word → Word and Word → other writing environments.

## Requirements

- Apple Silicon Mac
- macOS 11 Big Sur or later
